CTPlay uploader

This page turns the official Circuit Tracks firmware into CTPlay and sends it to your Circuit Tracks. It all happens in your browser. No Novation code is included: your own firmware file is changed on your computer, for a device you own.

Before you start

  • Back up. Save your projects and samples with Novation Components. Copy the microSD card to your computer.
  • Use desktop Chrome or Edge. Other browsers can't send firmware.
  • Close Components, any DAW and other MIDI pages. On Windows only one app can use a MIDI port, and Chrome keeps a tab's port until you close the tab.
  • Use this page only on a Circuit Tracks you own.

1 · Get the official firmware

Download Circuit Tracks 1.2.1 (build 4486) from Novation: circuittracks-firmware-4486.syx. This is Novation's own download, the one Components uses. If the link stops working, use a copy you kept.

Then pick the file here. A .syx file or a .bin image both work. The file stays on your computer.

2 · Choose what to install

3 · Connect

Connect the Circuit Tracks with USB and switch it on as usual. Press Allow MIDI, then Identify the device: the page learns which build is installed.

Then put it in bootloader mode: switch it off, hold Scales + Preset + Note and switch it on. Press Identify the device again.

Output to the Circuit Tracks

Input from the Circuit Tracks

Without this box the page sends only in bootloader mode. A send to the running firmware once reported success while the device kept its old firmware.

4 · Send

When the device asks, press Play on the Circuit Tracks. Once it has received everything, it restarts. It installs the file only if it is a different version from the one installed. Don't unplug it until it has started again.

If it goes wrong

  • A failed or aborted send changes nothing. The Circuit Tracks keeps its old firmware.
  • If the Circuit Tracks doesn't start:
    1. Unplug it.
    2. Hold the power button for 15–30 s.
    3. Hold Scales + Preset + Note and switch it on. This is bootloader mode.
    4. On this page, choose Official 1.2.1 and send it.
  • More in the guide: Going back to the official firmware.
